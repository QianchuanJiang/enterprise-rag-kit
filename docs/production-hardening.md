# 工业生产落地前置工作清单

> 本文从 `docs/evaluation.md` 第六节拆出，汇总「将本项目能力用于真实工业生产所需完成的前置工作」。
> 项目性质声明仍见 `docs/evaluation.md` 第六节：本项目为演示与研究性质的参考实现，**不含有任何真实企业的保密或生产数据，不能直接用于工业生产环境**。

---

若要将本项目的能力用于真实工业生产，至少需完成以下六类工作：

1. **真实数据接入与脱敏管道**
   - 建立真实文档摄入管道（连接器 / 定时同步）；
   - 实现生产级脱敏：PII 自动遮蔽、密级识别与标注、不可逆脱敏留痕；
   - 数据合规审查（来源授权、使用范围、留存期限）。

2. **身份与权限体系对接**
   - 对接企业真实 IAM / SSO（LDAP / OIDC / 钉钉 / 企微等），以真实组织角色驱动 ACL；
   - 将配置映射升级为动态权限策略，支持细粒度与多租户。

3. **安全加固**
   - 传输与存储加密、密钥管理；
   - 向量库与生成服务的访问鉴权、网络隔离；
   - 输入 / 输出内容安全过滤，防止提示注入与数据外泄。

4. **高可用与可运维**
   - 服务冗余、负载均衡、自动故障转移；
   - 数据备份与灾难恢复（含向量库持久化与回滚）；
   - 日志、指标、链路追踪与告警。

5. **评测与质量保障升级**
   - 在真实业务数据上重建评测集，扩大样本规模；
   - 引入回归测试与持续评测流水线；
   - 性能压测（并发、延迟、容量）达到生产目标。

6. **合规与审计**
   - 通过必要的行业合规认证（如等保、ISO 27001 等，视行业而定）；
   - 完善不可篡改审计链，满足金融 / 医疗 / 政企的审计要求；
   - 第三方安全渗透测试。
