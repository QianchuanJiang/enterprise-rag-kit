# 场景 A · 异构文档知识库（年报 / 招股书问答）—— 功能清单与验收标准

> 文档性质：**需求与功能层**，不含实现细节。
> 阶段定位：3 个核心场景之一（A/B/C）。本步只定 A 的功能与验收；B（合规权限）、C（离线私有化）后续单独定。
> 决策记录：场景数量 = 3 核心（A/B/C）；A 第一版范围 = 全做；数据来源 = 上市公司年报 / 招股书（巨潮网公开披露）。

---

## 1. 定位与目标买家

| 项 | 内容 |
|---|---|
| 一句话价值 | 把「通用方案解析错的复杂文档」做对，且回答可溯源、敢拒答 |
| 目标买家 1 | 制造业信息化部 / 厂长（设备手册、工艺规程、维修记录） |
| 目标买家 2 | 法务 / 律所合伙人（合同、判例、法规） |
| 目标买家 3 | 金融研究机构（年报、招股书、研报） |
| 差异化锚点 | 跨页表格还原、扫描件 OCR、页眉页脚噪声——这三类坑通用方案普遍做不对 |

> 选年报 / 招股书的原因：它是**公开数据里版式复杂度最接近企业真实文档**的。企业内部的设备手册、工艺规程、合同模板，坑型与年报高度一致（跨页合并报表、图文混排、扫描件、页眉页脚噪声）。

## 2. 数据来源与合规

| 项 | 说明 |
|---|---|
| 来源 | 巨潮资讯网（cninfo.com.cn）公开上市公司年报、招股说明书 |
| 规模 | 30–50 份 PDF，约 5,000–10,000 页 |
| 特点 | 大量跨页表格、图文混排、部分扫描件、页眉页脚噪声重 |
| 许可证 | 公开披露文件，仅用于技术验证；演示与文章中**必须标注来源**，不主张版权 |
| 合规红线 | 不得包含任何现东家（弘象科技）资产、客户数据、架构图 |

## 3. 功能清单（需求级）

### 模块 1 · 文档接入
- **F1.1 格式支持**：PDF（文字版 + 扫描版）、Word(.docx)、网页 / Markdown
- **F1.2 批量入库**：支持整目录批量导入
- **F1.3 容错降级**：单文件解析失败不中断整批，记录失败原因并跳过

### 模块 2 · 解析质量（A 的立身之本）
- **F2.1 跨页表格还原**：大表拆成「属性-值对」独立存储，不被切片切散
- **F2.2 扫描件 OCR**：无文字层 PDF 自动识别并走 OCR（中文场景）
- **F2.3 噪声清洗**：页眉页脚、目录页码、水印自动剔除
- **F2.4 标题层级保留**：保留文档结构，供按层级切片使用

### 模块 3 · 检索
- **F3.1 混合检索**：稠密向量（语义）+ BM25（关键词 / 型号 / 代号 / 人名）双路
- **F3.2 两段式重排**：粗筛 Top-K → 重排模型 → 精排 Top-N
- **F3.3 Query 改写**：口语化提问改写为检索友好表达
- **F3.4 可解释召回**：返回每条召回的来源、页码与命中理由

### 模块 4 · 问答
- **F4.1 强制溯源**：每个结论标注来源文档 + 页码
- **F4.2 无据拒答**：检索置信度低于阈值时输出「知识库未找到相关依据」，不编造

### 模块 5 · 评测与证据（说服力的来源）
- **F5.1 离线指标**：解析成功率、表格还原准确率、Recall@k、Faithfulness、拒答准确率
- **F5.2 对照实验表**：纯向量 → +BM25 → +重排 → +改写 的召回率递进（证明「你知道坑在哪、以及如何解决」）

### 模块 6 · 演示物料
- **F6.1 录屏**：3 分钟真实交互演示（无重度剪辑）
- **F6.2 README 指标表**：指标与对照实验置顶
- **F6.3 踩坑文章**：一篇技术复盘（跨页表格 / 噪声清洗等），发掘金 / 知乎 / 公众号

## 4. 验收标准（可量化）

| 编号 | 维度 | 指标 | 目标值 | 测量方式 |
|---|---|---|---|---|
| AC-1 | 解析 | 解析成功率（成功提取正文页占比） | ≥ 95% | 全量页面统计 |
| AC-2 | 表格 | 表格还原准确率 | ≥ 85% | 抽样 50 个表格人工核对 |
| AC-3 | 检索 | Recall@10 | ≥ 85% | 人工标注 50 条问答对 |
| AC-4 | 生成 | Faithfulness | ≥ 0.85 | RAGAS 评测 |
| AC-5 | 生成 | Answer Relevancy | ≥ 0.80 | RAGAS 评测 |
| AC-6 | 拒答 | 拒答准确率 | ≥ 90% | 30 条「知识库中不存在」的问题 |
| AC-7 | 对照 | 纯向量召回递进 | 58% → 82% | 四级配置对照实验 |

> **AC-7 是 A 最有说服力的一栏**：它直接证明你比甲方更早知道坑在哪、以及怎么解决——这是甲方愿意付溢价的原因。

## 5. 范围边界

**本阶段含**：模块 1–6 全部功能 + 上述 7 条验收标准。

**本阶段不含**（属其他场景，避免返工）：
- 分级权限 / 审计 / 防泄漏 → 场景 B
- 离线私有化部署 / 信创（昇腾 + 麒麟）适配 → 场景 C
- 分层调度降本（规则→7B→72B） → 可选 D

**与 B/C 的衔接**：A 的解析 / 切片 / 检索 / 生成模块将被 B、C 复用为同一套底座；差异仅在配置与数据，不在代码。这意味着 A 做扎实后，B、C 的边际交付时间可压到 20 小时以内。
